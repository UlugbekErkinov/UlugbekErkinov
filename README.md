## About

Software engineer at [UZINFOCOM](https://uzinfocom.uz), Tashkent. For 4+ years I have designed and built Python backends where reliability matters: LLM products that serve users in Uzbek, Russian, and English, real-time customer communication, and payments.

I care about measurable quality. Model and retrieval changes go through evals before release, risky checks ship in shadow mode first, and money-moving code is idempotent by design.

## What I build

| Area | Highlights |
|---|---|
| **LLM systems** | LoRA fine-tuning of a 100B+ parameter open-weight model, self-hosted behind an OpenAI-compatible API · multi-tenant RAG with hybrid search and reranking · agents with tool calling and self-hosted SearXNG web search |
| **Evaluation & observability** | Eval pipeline with MRR, Recall@k, NDCG, LLM-as-judge, and promptfoo in CI · hallucination guard made 2,600× faster · Prometheus, Grafana, and OpenTelemetry tracing for AI requests |
| **Real-time communication** | Architecture of an omnichannel support SaaS (web, Telegram, WhatsApp, Instagram, Slack) · WebRTC audio/video calls with LiveKit and coturn · Asterisk telephony with IVR, queues, and transfers |
| **Payments** | Subscription billing with idempotent card charges · FastAPI payment microservices at upay.uz · 72% faster PostgreSQL queries |

> Most of my production work lives in private company repositories. Public repositories here are side projects and experiments.
